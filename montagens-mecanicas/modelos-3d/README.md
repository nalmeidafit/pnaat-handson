# Montagens mecânicas

Esta pasta concentra os arquivos mecânicos utilizados no protótipo do workshop PNAAT.

## Estrutura

```text
montagens-mecanicas/
└── modelos-3d/
    ├── README.md
    ├── *.stl
    └── *.step
```

Os modelos destinados à impressão 3D devem ficar em `modelos-3d/`.

## Convenção recomendada

Para cada conjunto, manter quando possível:

- arquivo `.STL` pronto para fatiamento;
- arquivo `.STEP` ou outro formato CAD editável;
- breve descrição da função da peça;
- material de impressão recomendado;
- orientação de impressão;
- necessidade ou não de suportes;
- observações de montagem.

Os arquivos mecânicos ainda serão adicionados conforme forem consolidados para a bancada definitiva.
